# help-desk

Локальное браузерное приложение для анализа TXT-отчётов сравнения/объединения 1С.

## Что умеет

- Загружает отчёт `.txt` в браузере без backend.
- Авто-декодирует UTF-16LE (BOM) и UTF-8.
- Парсит конфликты 1С-отчёта:
  - `Изменено: X - Y`
  - `Объект присутствует только в основной конфигурации`
  - `Объект присутствует только в файле`
- Автоматически классифицирует изменения по **группам объектов** без хардкода (например: `ОбщийМодуль`, `Справочник`, `Документ`, и т.д. — по префиксу метаданных из отчёта).
- Показывает изменения в двух режимах:
  - дифф с подсветкой конкретного изменённого фрагмента внутри строки;
  - табличный режим для мета-параметров (`было / стало`), если отчёт содержит такие блоки.
- Поддерживает фильтры и навигацию:
  - поиск,
  - фильтр по группе,
  - фильтр по типу изменения,
  - фильтр по риску,
  - сортировка,
  - коллапсируемые блоки конфликтов.

## Анализ формата `test_documents/TestReport.txt`

- Файл имеет UTF-16LE BOM.
- Использует табуляцию как уровень иерархии объектов.
- Маркеры в начале:
  - `***` — объект изменён,
  - `-->` — только в основной,
  - `<--` — только в файле,
  - `^-` — изменён порядок.
- Содержимое diff-блоков задаётся строками:
  - `< ...` (левая/основная сторона),
  - `> ...` (правая/файл),
  - либо кавычками `"..."`.

## Запуск

Откройте `index.html` в браузере
или запустите локальный сервер:

```bash
python -m http.server 4173
```

Далее откройте: `http://localhost:4173`.

## Ограничения текущей версии

- В этой итерации **убрана логика merge/resolve** — приложение фокусируется на анализе и визуализации конфликтов.
- Для нестандартных/редких форматов выгрузки 1С может потребоваться расширение эвристик парсинга.
